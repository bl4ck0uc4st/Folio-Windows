FOLIO WINDOWS — PORTABLE, LOCAL PDF TOOLS

GET STARTED
1. Right-click the ZIP and select Extract All.
2. Choose a local folder, for example C:\LocalTools\Folio.
3. Open Start-Folio.cmd. It opens the app in Microsoft Edge or Chrome.
   You can also right-click Folio-Windows.html > Open with > Microsoft Edge.
4. Pick a tool, then choose files or drag files into it.
5. Click the main action button to save your result.

No installer, account, Python, Node.js, administrator access, or server is
needed to use the app. The HTML file contains the application and libraries.
The source folder is optional; it is only for rebuilding the adaptation.

KEEP FILES ONLY ON THIS COMPUTER
- All document processing happens in your browser on this computer.
- The app blocks internet, LAN, and localhost connections. The phone helper
  has been removed. You can turn Wi-Fi off and continue using every tool.
- Save the app and results outside OneDrive, Dropbox, network shares, and
  other synchronized folders if you want them only on this computer.
- To choose a save folder each time, enable "Ask me what to do with each
  download" in Edge or "Ask where to save each file before downloading" in
  Chrome's Downloads settings. The app uses your browser's download controls.
- Opened files are held in memory. Close all Folio windows when finished.
- Settings are stored in this browser. Signatures are stored only when you
  select "Remember on this PC". Click the privacy stamp at the lower left
  for details or to forget saved signatures.
- Browser extensions, Windows, and external backup/sync programs have their
  own settings. The app's network policy governs the app itself.

TOOLS
Organize: merge PDFs/images, split/extract/delete pages, reorder, rotate, crop.
Edit and sign: text, notes, highlights, drawing, shapes, images, white-out,
  redaction, signatures, initials, dates, checkmarks, and page numbers.
Optimize: PDF compression.
To PDF: images; local scan/photo cleanup; Word (.docx), PowerPoint (.pptx),
  Excel (.xlsx), and CSV/TSV.
From PDF: JPG, Word (.docx), PowerPoint (.pptx), and Excel (.xlsx).

WINDOWS SHORTCUTS
Ctrl+O         Add files to the current tool.
Ctrl+K         Find a tool.
/              Find a tool from the home screen.
Ctrl+Z         Undo in the editor or page organizer.
Ctrl+Shift+Z   Redo in the editor.
Ctrl+Y         Redo in the editor.
Ctrl+D         Duplicate the selected annotation.
Delete         Remove the selected annotation/page where supported.

SCANS
Scan pages to JPG/PNG using your scanner's software, or choose photos already
saved on this PC. Open Scan to PDF, add images, adjust the corners, choose
Original/Clean/Grayscale/Black & white, and create a PDF.
This edition does not connect to a phone or a network scanning helper.

KNOWN LIMITATIONS
- Office conversion reconstructs the layout; complex documents may differ
  from Microsoft Office. Use Office's own PDF export for an exact layout.
- Office charts and unsupported EMF/WMF pictures may appear as placeholders.
- Scanned PDFs do not have editable text unless they already contain a text
  layer. This build does not add OCR.
- If an HEIC photo is not supported by the browser, save it as JPG/PNG first.
- Password-protected Office documents must be unlocked before importing.
- A drawn/typed signature is a visual signature, not a certificate-based
  cryptographic digital signature.
